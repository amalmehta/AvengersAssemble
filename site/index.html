Avengers Assemble

A Mac app that runs a company of AI agents. Give it a goal; a CEO plans the work, and multi-armed bandits learn which specialist, on which Claude model, should do each task.

How it works

A team that learns who should do what.

Every task is a small experiment. The result is scored, and the score teaches the next decision, for this run and every run after.

The CEO plans

Your goal, plus any files you drop in, becomes 4–10 concrete tasks, each with a kind and its dependencies.

A bandit picks the agent

Thompson sampling chooses a specialist from what the task's kind and wording have earned before.

A second bandit picks the model

Opus, Sonnet or Haiku, paying for cost, so a cheaper model that's nearly as good wins over time.

Agents do the work

They search the web, read your PDFs and images, write files and run sandboxed Python, several tasks at once.

A reviewer scores it

Every result gets 0 to 1. Your 👍 or 👎 overrides the score and counts three times as much.

The team

Ten specialists and a reviewer.

Each agent is a YAML file you can edit: its role, skills, allowed models and prompt. Add a file to add an agent.

Learning

It gets better the more you use it.

Routing reads what a task says, not just its kind, so a "battery" task filed under hardware can go to the physicist. In simulation, that sends more work to the right agent.

What's inside

Built to be useful, and safe to leave running.

📎

Reads what you give it

Drop in PDFs, photos, screenshots, Word, Excel and PowerPoint files. Agents see images and PDFs as they are, with tables and figures intact.

🧪

Sandboxed by default

Agent code runs with no network and can only write inside the run's workspace. Nothing is sent, bought or published.

💸

Budget caps

Every run stops at a dollar cap and a task cap you set, and still writes its report.

🔍

Explains every choice

See each agent's sampled score and the similar past tasks behind every routing decision, even for old runs.

⚡️

Parallel work

Independent tasks run side by side (three at a time by default), while routing decisions stay in order.

✈️

Works offline too

No API key yet? An offline mock runs the whole system, so you can explore it at no cost.

Get started

Up and running in a few minutes.

Download the app

  1. Install uv, which runs the app's Python engine: 
    curl -LsSf https://astral.sh/uv/install.sh | sh
  2. Download, unzip and move Avengers Assemble to Applications.
  3. Open it once. The app isn't notarized by Apple yet, so macOS will block it the first time. Go to System Settings → Privacy & Security and click Open Anyway.
  4. Wait about 20 seconds on first launch while the engine sets itself up.
  5. Add your Anthropic API key in Settings (⌘,), or leave the offline mock on to try it for free.
Download for Mac

Or build it from source

Needs Xcode or the Command Line Tools, and uv.

git clone https://github.com/amalmehta/AvengersAssemble.git
cd AvengersAssemble
./scripts/build-app.sh
open "build/Avengers Assemble.app"

Or run the engine on its own, from the command line:

cd engine
uv run suite run "Start a drone delivery company" --mock

Full instructions, system design and file map are on GitHub.
